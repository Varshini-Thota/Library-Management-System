# Library Management System

## Overview

The Library Management System is a C programming project designed to manage library books through a menu-driven interface. It allows users to add books, search for books, issue books, and return books efficiently.

## Features

* Add New Books
* View Available Books
* Search Book by ID
* Issue Books
* Return Books
* Menu-Driven Interface
* Book Availability Status Tracking

## Technologies Used

* C Programming Language
* OnlineGDB

## How It Works

1. Users can add books by entering the book ID and title.
2. All stored books can be viewed along with their availability status.
3. Books can be searched using their ID.
4. Available books can be issued to users.
5. Issued books can be returned and marked as available again.
